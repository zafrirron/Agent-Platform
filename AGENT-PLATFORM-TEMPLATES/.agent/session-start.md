# Agent Platform — session start

**Universal command (works in any IDE):**
`Read .agent/session-start.md and execute it.`

---

## Step 0 — Identify your framework

You know which IDE you are. Map it to a framework folder name:

| You are | Framework folder name |
|---------|----------------------|
| Claude Code | `claude` |
| Cursor | `cursor` |
| Antigravity | `agents` |
| Codex (VS Code) | `codex` |
| OpenCode | `opencode` |

If uncertain, check which private folder exists in this repo (`.claude/`, `.cursor/`, `.agents/`, `.codex/`, `.opencode/`), or default to `claude`.

---

## Step 1 onwards — Execute shared logic

Read `.agent/session-start-shared.md` and execute it, replacing every `<fw>` with the framework folder name you identified above.
