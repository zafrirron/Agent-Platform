# Architecture Decision Records — {{PROJECT_NAME}}

> **ADR = Architecture Decision Record.** A short note capturing *why* a hard-to-reverse choice was made.
> NNN = sequential number: ADR-001, ADR-002, etc.
>
> Log any choice that would cost time to reverse or re-examine: framework selection, API design,
> database choice, deployment model, authentication strategy, major refactor decisions.
>
> Agents read this before designing new features — prevents relitigating settled choices.
